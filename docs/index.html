About This Dashboard

This dashboard tracks selected measures for Cambridge's Open Data Program, aligning with the FY 2026-2028 strategic plan's focus on cultivating a sustainable data ecosystem. The plan frames open datasets as the "soil" that supports public transparency, City decision-making, community research, and responsible innovation.

The Open Data Program is the City's central hub for sharing and using data to improve transparency, collaboration, and decision-making. This placeholder should eventually summarize the metric sources, refresh cadence, and how the dashboard will be used to monitor progress. Read the full Cambridge Open Data Strategic Plan 2026-2028.

Strategic Priorities and Metrics

  1. Cultivate a Sustainable Data Ecosystem Tracks dataset inventory, dataset creation, usage, searches, licensing, automated refresh, freshness, categories, and keywords. Missing: pre-2020 usage history and fuller lifecycle or retirement measures.
  2. Strengthen Data Governance and Protect Privacy Tracks datasets with privacy or geomasking notes. Missing: privacy inquiries, published governance updates, and public attendance at Open Data Review Board meetings.
  3. Engage Consistently with the Public Tracks indirect engagement through referrer visits and referring domains. Missing: newsletter issues, subscribers, workshops, attendance, targeted outreach, and Big Issues talks.
  4. Empower City Departments as a Connector and Enabler Tracks internal portal accounts, logins, and department metadata coverage. Missing: CDAG meetings, CDAG attendance, departments represented, staff trainings, and staff training attendance.
  5. Encourage Responsible Innovation Planned metrics cover emerging tool evaluations, documented pilots, and tools or methods adopted. These are not yet populated from Socrata and need a program tracker or manual source.
  6. Strengthen Partnerships in the Broader Data Ecosystem Planned metrics cover academic collaborations, civic tech collaborations, regional or national convenings, shared outputs, and external references. These also need non-Socrata tracking.
