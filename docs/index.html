About This Dashboard

This dashboard tracks selected measures for Cambridge's Open Data Program, aligning with the FY 2026-2028 strategic plan's focus on cultivating a sustainable data ecosystem. The plan frames open datasets as the "soil" that supports public transparency, City decision-making, community research, and responsible innovation.

The Open Data Program is the City's central hub for sharing and using data to improve transparency, collaboration, and decision-making. This placeholder should eventually summarize the metric sources, refresh cadence, and how the dashboard will be used to monitor progress.

Strategic Plan Themes

Build the foundation Publish and steward high-value datasets that are reliable, current, documented, and easy to find.
Protect public trust Strengthen data governance, privacy practices, and clear documentation as the portal grows.
Engage and enable Use regular public engagement and department support to help more people turn open data into useful civic work.
